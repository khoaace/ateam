Cài đặt

Chạy trên macOS và Linux. Một lệnh là xong; nâng cấp cũng chạy lại đúng lệnh đó.

Cài bằng một lệnh

curl -fsSL https://raw.githubusercontent.com/khoaace/ateam/main/scripts/get.sh | bash

Hoặc từ file đã tải

cd ~/Downloads && unzip -o {{ZIP_NAME}} && cd ateam && ./install.sh
ateam doctor

Mở dự án và gõ ateam. Lần đầu mở, ateam hỏi sẵn danh sách model của từng CLI rồi hiện một màn hình để chọn agent, trưởng nhóm, model và effort (mở lại bằng /setup). Lệnh ateam doctor cho biết agent nào đã sẵn sàng và đúng lệnh sẽ chạy cho từng agent.

Cần có

  • Python 3.9+ — brew install python nếu thiếu
  • git cho chế độ worktree và xem diff
  • Ít nhất một agent CLI đã đăng nhập: claude, codex, agy, opencode, hoặc bất kỳ CLI nào có chế độ headless

ateam dùng gói đăng ký sẵn có của từng CLI, không cần API key riêng. Mọi dữ liệu của dự án nằm trong thư mục .ateam/, đã tự gitignore.

Một mục tiêu đi qua đội như thế nào

Bạn chỉ cần gõ một câu. Phần còn lại diễn ra trên bảng việc chung, và bạn chen vào bất cứ bước nào.

  1. Giao mục tiêu

    Gõ yêu cầu như viết ticket: kết quả cần có và cách kiểm tra.

  2. Trưởng nhóm lập kế hoạch

    Chia thành 1–8 task, chọn agent, thứ tự phụ thuộc và effort cho từng task.

  3. Bạn duyệt

    Đổi người làm, sửa, huỷ task nháp, rồi Ctrl+G để chạy.

  4. Các agent làm song song

    Task chạy khi task trước xong; agent có thể giao phần việc hợp với thành viên khác.

  5. Kiểm tra và duyệt

    Test fail thì tự giao sửa. Ở chế độ review, bạn xem diff rồi merge hoặc trả lại kèm góp ý.

  6. Trưởng nhóm review

    Đủ thì đóng mục tiêu; còn thiếu thì giao thêm việc, tối đa 3 vòng.

Có gì trong ateam

Những thứ bạn sẽ dùng mỗi ngày khi để nhiều agent cùng làm một repo.

Tab Đội, xem cả 4 agent cùng lúc
Mỗi agent một ô log trực tiếp, task đang làm, thời gian chạy, cảnh báo khi im lặng quá lâu, và timeline ai làm gì lúc nào.
Tự chạy test, fail thì tự sửa
/verify npm test một lần cho mỗi dự án. Task đổi code mà test fail sẽ được giao sửa kèm log lỗi, tối đa 2 lần.
Duyệt diff trước khi merge
Mỗi task một git worktree riêng. Ctrl+D xem diff, Ctrl+Y merge, /reject kèm góp ý để làm lại.
Hết hạn mức thì đổi người
Agent báo rate limit được cho nghỉ đến giờ hồi; task tự chuyển sang agent dự phòng, kể cả vai trưởng nhóm.
Model và effort cho từng agent, từng task
/model claude opus, /effort codex xhigh, hoặc /task codex@xhigh … cho riêng một việc khó.
Trưởng nhóm hỏi kỹ trước khi làm
/grill <mục tiêu>: trưởng nhóm hỏi bạn từng câu — phạm vi, luồng, ca biên, tiêu chí xong — kèm phương án gợi ý, rồi chốt bản đặc tả và mới lập kế hoạch.
Xem & sửa code kiểu vim
Tab 📝 Code (/code @file:dòng): tô màu cú pháp, phím vim (dd, cw, /tìm, :w…), nhiều file, tự nạp lại khi agent sửa file — vẫn mượt với file hàng chục nghìn dòng. /vim off nếu muốn sửa kiểu thường.
Quản lý git ngay trong app
Tab 🌿 Git (/git): stage từng file, xem diff, commit — trưởng nhóm viết commit message từ diff —, đổi/tạo/merge nhánh, pull/push, stash, lịch sử và revert.
Theme màu và tiếng Anh
/theme chọn 1 trong 21 theme tối/sáng cộng màu nhấn, xem trước trực tiếp; /lang en chuyển toàn bộ giao diện và lệnh ateam sang tiếng Anh.
Agent và workflow của riêng bạn
Bất kỳ CLI nào chạy headless đều vào đội được: Gemini CLI, Cursor CLI, Aider… thêm trong màn hình /custom (có mẫu và xem trước lệnh). Workflow dựng sẵn như thiết kế → code → test chạy bằng /flow <tên> <mục tiêu>.

Cấu hình

File chung ở ~/.config/ateam/config.toml; mỗi dự án ghi đè bằng .ateam/config.toml (tạo bằng ateam init --project).

# chạy song song an toàn: mỗi task một nhánh, chờ bạn duyệt
isolation = "worktree"
merge = "review"

[verify]
command = "npm test"
max_fix_attempts = 2

[agents.codex]
command  = ["codex", "exec", "--sandbox", "workspace-write", "--skip-git-repo-check", "{prompt}"]
model    = "gpt-5.5"
effort   = "high"
fallback = ["claude"]
role     = "Viết code, sửa bug, chạy test, refactor."

# thêm bất kỳ CLI headless nào
[agents.gemini]
command    = ["gemini", "--yolo", "-p", "{prompt}"]
model_args = ["--model", "{model}"]
role       = "Đọc codebase lớn, viết tài liệu."
